# e-plantShopping

## Paradise Nursery

Paradise Nursery is a React-based online plant shopping application.

### Features

- Browse plants by category
- View plant images, names, descriptions and prices
- Add plants to the shopping cart
- Increase or decrease plant quantities
- Remove plants from the cart
- View total cart amount
- Continue shopping from the cart

### Technologies

- React
- JavaScript
- Redux Toolkit
- CSS
- Vite
